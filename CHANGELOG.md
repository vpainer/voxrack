# Changelog

All notable changes to VoxRack are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/),
versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-10-16

First public release.

### Added
* Real-time voice chain as a Windows APO on the microphone itself: low cut, gate, autotune, 10-band EQ,
  4-band multiband compressor, compressor, de-esser, delay, reverb, look-ahead limiter.
* Reorderable chain (drag, right-click, Alt+↑/↓); input/output first, limiter last.
* Multiband editor in the spirit of FabFilter Pro-MB: bands on the live spectrum, floating band panel.
* Live spectrum before/after, gain-reduction history, compressor transfer curve, autotune pitch track.
* Per-microphone settings (OWN / SHARED), MATCH (fit a microphone to a reference), TAKE (loop a phrase, wet/dry),
  MON (hear yourself processed), presets.
* Shure MV7 extras: LED modes, touch lock, identify.
* WinUI 3 app with Mica, light/dark theme and accent color from Windows, English and Russian, collapsible sidebar.
* Update check against GitHub Releases, About dialog, Support link.
